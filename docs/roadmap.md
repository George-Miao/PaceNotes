# Roadmap

## Current MVP

- Fixed-date trips with places and free-form itinerary items
- Smart placement of new places by schedule fit and Google route cost
- Live Yjs collaboration for up to 10 editors
- Random full-access trip URLs without accounts
- Google place search, map, routes, and transient place details
- PostgreSQL durability and one-host Docker Compose deployment
- Installable web application shell

## Next

- Authentication, named accounts, roles, and controlled trip access
- Secret-link rotation and stronger sharing controls
- Operator-selectable place and route providers
- Additional open review and description sources
- Export and import tools

## Later

- Offline trip editing and conflict recovery after long disconnections
- Attachments, budgets, and booking inbox integration
- Native mobile applications
- Rich structured note editing
- Larger trip and editor performance envelopes

Roadmap items are not part of the current product contract. The application must not show a control that has no complete behavior.
